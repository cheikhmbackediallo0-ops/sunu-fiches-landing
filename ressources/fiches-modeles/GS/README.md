## Les 3 trames utilisées

Le détail de chaque trame est en tête de [fiches-gs-transcription.md](fiches-gs-transcription.md).

1. **Trame IST** (« Tâches du MAÎTRE / Tâches des ENFANTS / Matériels / Tps »)
   Préalables (3 mn) → Révision (3 mn) → Mise en situation (3 mn) → Exploitation de la situation (7 mn) → Consolidation (3 mn) → Évaluation (2 mn). Total : 21 mn.
2. **Trame Mathématiques** (mesure, numériques — « Tâches de l'éducateur(trice) / Tâches des enfants », avec ligne **JEU(X) ASSOCIÉ(S)**)
   Préalables → Révision → Mise en situation (annonce + justification de l'OS) → Présentation de l'éducatrice (modélisation) → Pratique guidée → Pratique autonome → Objectivation → Évaluation.
3. **Trame Vocabulaire** (avec lignes **S/DOMAINE**, **OBJECTIF D'APPRENTISSAGE**, **CORPUS**)
   Préalables → Révision → Mise en situation → Présentation de l'enseignant(e) (Modélisation) → Pratique guidée (jeu de planches / loto / dé) → Pratique autonome (Memory, cartes) → Objectivation.
